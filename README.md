# JSMusic 🎵

API REST para gerenciamento de uma plataforma musical, desenvolvida com **C#, ASP.NET Core 10, Entity Framework Core e SQL Server**.

## 🚀 Funcionalidades

- Gerenciamento de usuários, artistas, álbuns, músicas e gêneros.
- Associação entre artistas, álbuns, músicas e gêneros.
- Validação de dados e relacionamentos.
- Hash de senhas utilizando BCrypt.
- Documentação interativa com Swagger.

## 🛠️ Tecnologias

- C#
- ASP.NET Core 10
- Entity Framework Core 10
- SQL Server
- Swagger / OpenAPI
- BCrypt

## ⚙️ Como executar
git clone URL_DO_REPOSITORIO
cd JSMusic
dotnet restore
dotnet run

Configure a conexão com o SQL Server antes de executar.

## 📚 Documentação

Com a aplicação em execução, acesse:
